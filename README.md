# Proxy Courses

A peer-tutoring and advising platform for IUB students. This is the CSE451 / CSC445 Software Engineering
semester project, Autumn 2026, at Independent University, Bangladesh. Faculty: Md Masum Billah.

**Team:** Syed Mehedi Hussain (2310690) · Arafat Hossain (2420834) · Rukaiya Tabassum (2420183) · Meharab Hossen Opi (2420832)
